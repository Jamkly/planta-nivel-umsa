# Planta de Nivel — UMSA

## Descripción
Repositorio académico destinado a organizar y conservar la documentación técnica de la planta de nivel, incluyendo los trabajos actuales y los antecedentes de semestres anteriores.

## Objetivos
- Organizar la documentación técnica y los planos de ingeniería.
- Conservar informes, presentaciones, diagramas y códigos de semestres anteriores.
- Documentar el diseño de la base de datos.
- Facilitar el trabajo colaborativo mediante Git y GitHub.
- Preparar un portal web para consultar los documentos.

## Estructura del repositorio
- `documentacion/`: documentación de los laboratorios actuales.
- `database/`: modelos y scripts de la base de datos.
- `semestres/`: archivo histórico de trabajos académicos.
- `global/`: manuales y recursos técnicos compartidos.
- `web/`: archivos de la página web.
- `config/`: configuración del catálogo documental.
- `evidencias/`: evidencias e historial del proyecto.

## Videos
Los videos se alojan en Google Drive. Los enlaces se organizan en archivos de índice dentro de las carpetas correspondientes a cada semestre.

## Trabajo colaborativo
Los cambios se registran mediante commits y se proponen a través de Pull Requests antes de integrarse en la rama principal `main`.
